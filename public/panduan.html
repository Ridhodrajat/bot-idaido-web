Panduan Penggunaan


## Mulai Menggunakan Bot

Sebelum mulai, pastikan:
1. Bot sudah diundang ke grup oleh owner
2. Masa sewa sudah aktif (owner mengaktifkan dengan `.addsewa`)
3. Anda admin grup, dan bot juga dijadikan admin agar bisa moderasi dan mengubah info grup

### Langkah 1: Buka Menu
Kirim perintah berikut di grup:
```
.menu
```

### Langkah 2: Isi Katalog
Kirim `.addlist` lalu ikuti petunjuk bot untuk mengisi nama, harga, dan foto produk.
Cek hasilnya dengan:
```
.list
.previewlist
```

### Langkah 3: Pilih Template Pesan
Pilih gaya pesan proses dan pesan selesai:
```
.setproses
.setdone
```
Pesan buka dan tutup grup diatur dengan `.setopen` dan `.setclose`.

### Langkah 4: Pesan Sambutan
Kelola welcome dan goodbye:
```
.welcome
.goodbye
.setwelcome
.setleft
```

### Langkah 5: Moderasi Grup
Aktifkan proteksi grup dan catat nomor pengganggu:
```
.antilink
.antiwame
.addblacklist
```

Selesai! Bot siap beroperasi.

Alur Kerja Harian


## Alur Kerja Harian

### Saat Ada Pesanan
1. Pelanggan mengetik `.list` atau nama produk di grup
2. Anda balas chat pelanggan lalu kirim `.p`
3. Bot mengirim template status diproses ke grup

### Saat Pesanan Selesai
1. Kirim akun/barang ke pelanggan
2. Balas chat pelanggan lalu kirim `.d 25000` sesuai nominal order
3. Bot mengirim nota selesai dan mencatat order ke laporan

### Buka & Tutup Grup
1. Buka grup dengan `.open`, tutup dengan `.close`
2. Atau aktifkan jadwal otomatis (`.autoopen`, `.autoclose`) agar bot mengunci grup sesuai jam operasional

### Laporan
Unduh rekap order dalam format Excel (.xlsx):
```
.dataordernow
.dataorderlast
.dataorderweek
.dataordermonth
```

FAQ Lengkap

Apakah saya perlu menyiapkan VPS atau server? ▼
Tidak perlu. Bot berjalan 24/7 di server kami. Kamu hanya perlu mengundang bot ke grup, lalu owner mengaktifkan sewa dengan perintah addsewa. Setelah itu bot langsung aktif tanpa setting teknis dan tanpa biaya server tambahan.
Bagaimana cara mulai menyewa bot? ▼
Proses sewa:

1. Pilih paket atau minta trial 7 hari
2. Hubungi owner via WhatsApp
3. Owner mengundang bot ke grup kamu
4. Owner mengaktifkan masa sewa
5. Bot langsung siap dipakai

Tidak ada instalasi yang perlu kamu lakukan sendiri.
Berapa lama durasi sewa? ▼
Fleksibel:

• Trial gratis 7 hari (kuota 300 balasan/hari, fitur premium terkunci)
• Sewa 7 hari
• Sewa 30 hari
• Durasi lebih panjang sesuai kesepakatan

Harga dan durasi bisa didiskusikan langsung dengan owner.
Satu sewa untuk berapa grup? ▼
Setiap sewa berlaku untuk satu grup. Setiap grup punya katalog, template, dan pengaturan sendiri. Jika kamu mengelola beberapa grup, hubungi owner untuk paket tambahan.
Apa yang terjadi setelah masa sewa habis? ▼
Bot berhenti melayani grup. Data grup tetap tersimpan selama 30 hari, jadi jika kamu memperpanjang dalam masa itu katalog dan pengaturanmu kembali seperti semula.
Apa yang terjadi kalau bot error atau tidak merespons? ▼
Hubungi owner via WhatsApp. Kami akan memeriksa, memperbaiki, dan melakukan restart bot jika diperlukan.
Apakah data toko saya aman? ▼
Data hanya dipakai untuk operasional grup kamu. Bot tidak membaca atau menyimpan chat pribadi, dan setiap grup memiliki data yang terpisah.
Apakah ada biaya tambahan selain sewa? ▼
Tidak ada. Biaya sewa sudah mencakup server dan operasional bot. Biaya transfer bank atau e-wallet ditanggung penyewa.

Troubleshooting

Bot tidak merespons perintah

  • Pastikan bot adalah admin grup
  • Cek apakah bot masih online (server hosting masih aktif)
  • Restart bot atau hubungi owner
  • Pastikan format perintah benar (dimulai dengan .)

Bot keluar dari grup sendiri

  • Bot mungkin di-remove by another admin
  • Bot crash karena error. Hubungi owner untuk restart
  • Masa sewa sudah habis

Laporan order tidak tergenerate

  • Pastikan pesanan ditandai selesai dengan \.d dan nominalnya ikut dikirim
  • Perintah laporan hanya tersedia di paket berbayar, bukan trial
  • Tunggu beberapa saat, bot mungkin sedang memproses file Excel

Harga di katalog tidak terupdate

  • Gunakan \.updatelist atau \.renamelist pada produk yang ingin diubah
  • Pastikan Anda admin grup dan bot juga admin
  • Cek hasil perubahan dengan \.list atau \.previewlist
