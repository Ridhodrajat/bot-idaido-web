## Quickstart untuk Admin Grup

Sebelum mulai, pastikan:
1. Bot sudah di-invite ke grup oleh owner
2. Anda adalah admin grup (atau buat grup baru dengan bot)
3. Bot adalah admin (berikan akses admin ke bot)

### Langkah 1: Jadikan Bot Admin
Kirim perintah ke grup:
```
.setadmin on
```

### Langkah 2: Setup Katalog
Buat katalog produk:
```
.addlist Netflix | Langganan Netflix 30 hari | 50000
.addlist Spotify | Langganan Spotify 1 bulan | 30000
```

Lihat katalog:
```
.list
```

### Langkah 3: Setup Template Pesan
Buat template untuk status pesanan:
```
.tempproses Template: Pesanan sedang kami proses, mohon ditunggu ya 🙏
.tempdone Template: Pesanan selesai! Akun sudah dikirim 🎉
```

### Langkah 4: Setup Jadwal
Setup jam buka dan tutup otomatis:
```
.autoopen on
.autoopenset 08:00
.autoclose on
.autocloseset 22:00
```

### Langkah 5: Aktifkan Moderasi
Setup antilink dan blacklist:
```
.antilink on
.addblacklist 62812xxxx Nama Penipu
```

Selesai! Bot siap beroperasi.

Alur Kerja Harian


## Alur Kerja Harian

### Pagi (Saat Buka Grup)
1. Bot otomatis buka grup (jika jadwal aktif)
2. Kirim sapaan ke group dengan `.announce Pagi! Grup sudah dibuka`

### Saat Ada Pesanan
1. Pelanggan chat atau kirim ke grup
2. Anda balas chat pelanggan
3. Kirim perintah `.proses` (balas chat pelanggan)
4. Template otomatis terkirim

### Saat Pesanan Selesai
1. Kirim akun/barang ke pelanggan
2. Kirim perintah `.done 50000` (balas chat dengan nominal)
3. Bot otomatis catat ke laporan

### Malam (Saat Tutup Grup)
1. Bot otomatis tutup grup (jika jadwal aktif)
2. Laporan otomatis di-generate ke Excel dengan `.dataordernow`

### Akhir Hari
1. Ekspor laporan dengan `.dataorderweek` atau `.dataordermonth`
2. Rekap omset dan pesanan

FAQ Lengkap

Apakah bot ini aman digunakan? ▼
Bot IDAIDO menggunakan library WhatsApp yang tidak resmi, bukan API resmi. Keamanan dan kestabilan bergantung pada perubahan WhatsApp. Kami rekomendasikan:

• Gunakan bot di akun admin, bukan akun pribadi utama
• Jangan bagikan sesi bot ke orang lain
• Matikan 2FA jika menyebabkan masalah koneksi
• Setujui disclaimer bahwa ini produk tidak resmi WhatsApp
Bot bisa digunakan di berapa grup? ▼
Tergantung paket:

• Starter: hingga 5 grup
• Professional: hingga 20 grup
• Enterprise: unlimited

Setiap grup bisa diatur terpisah dengan perintah konfigurasi.
Bagaimana cara sewa? ▼
Proses sewa:

1. Pilih paket yang sesuai
2. Hubungi owner via tombol WhatsApp di website atau chat langsung
3. Diskusikan detail (durasi, grup, custom request)
4. Lakukan pembayaran
5. Owner undang bot ke grup Anda
6. Ikuti panduan setup

Setelah itu bot siap digunakan.
Berapa lama durasi sewa? ▼
Durasi sewa fleksibel, contoh:

• 7 hari (1 minggu)
• 30 hari (1 bulan)
• 60 hari (2 bulan)
• Atau durasi custom sesuai negosiasi

Setelah habis, bot otomatis leave. Bisa perpanjang kapan saja.
Apa yang terjadi kalau bot error atau nggak merespons? ▼
Hubungi owner segera via WhatsApp. Owner akan:

• Cek error log bot
• Restart bot jika perlu
• Lakukan troubleshooting
• Ganti bot dengan yang baru jika tidak bisa diperbaiki

Garansi uptime 95% (bisa down untuk update/maintenance).
Bisa ganti nomor bot atau induk? ▼
Bisa, tapi perlu koordinasi dengan owner:

• Ganti nomor induk (pemberi perintah) bisa di tengah masa sewa
• Bot perlu restart dan re-login
• Hubungi owner untuk proses gangti nomor
Harga bisa berubah nggak? ▼
Ya, harga di website bisa berubah kapan saja tanpa notifikasi. Jika Anda sudah deal dengan owner pada harga tertentu, harga tersebut berlaku untuk sewa Anda.
Apakah ada biaya tambahan selain sewa? ▼
Tidak ada biaya tambahan dari sisi bot. Biaya yang mungkin ada:

• Biaya transfer (bank/e-wallet)
• Biaya internet untuk menjalankan induk bot (jika pakai komputer/VPS pribadi)

Semuanya ditanggung penyewa.

Troubleshooting

Bot tidak merespons perintah

  • Pastikan bot adalah admin grup
  • Cek apakah bot masih online (server hosting masih aktif)
  • Restart bot atau hubungi owner
  • Pastikan format perintah benar (dimulai dengan .)

Bot keluar dari grup sendiri

  • Bot mungkin di-remove by another admin
  • Bot crash karena error. Hubungi owner untuk restart
  • Masa sewa sudah habis

Laporan order tidak tergenerate

  • Pastikan Anda mengirim perintah \.done dengan benar
  • Tunggu beberapa saat, bot mungkin sedang memproses
  • Cek apakah bot bisa akses folder download (untuk file Excel)

Harga di katalog tidak terupdate

  • Gunakan \.editlist untuk edit harga
  • Format: \.editlist Netflix | Harga Baru | 60000
  • Pastikan Anda adalah owner atau yang punya akses edit
